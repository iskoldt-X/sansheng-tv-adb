# 中文提示词（没装 skill 时的手工流程）

把下面这段整个发给 Claude Code / Codex 这类能在你电脑上执行命令的 AI。只有两处要你填：品牌型号、电视 IP。要是你懒得填，直接把网页地址 sanshengai.top/tools/tv-adb 发给它也行，它会自己来读这一页。

---

我要你通过 ADB 清理家里的电视：去掉开机广告和推荐位、停用我从来不用的预装应用、把内存腾出来。命令你来执行，用平实的话告诉我你在做什么。

我的电视
- 品牌 / 型号：填这里（例：海信 65E3F、小米 EA55、Fire TV Stick 4K）
- 电视 IP：填这里（设置 → 网络里看，192.168 开头）
- 电脑和电视在同一个 Wi-Fi。开发者选项和 USB 调试我会按你说的步骤去开。

硬规矩（一条都不能破）
1. 不卸载任何系统应用，不 root，不解锁 bootloader，不刷机。只用能还原的停用命令。
2. 先判断值不值：连上后先读安卓版本和内存。安卓 4.x 直接告诉我「连得上改不了」并停止；不是安卓的系统告诉我不适用，改成教我在设置里关广告。
3. 先备份：动手前把 `pm list packages -f`、`pm list packages -d`、`pm list packages -u`、`dumpsys meminfo`、`cat /proc/meminfo`、`settings list global/system/secure`、`getprop` 各存成文件放进一个带日期的文件夹，告诉我路径。
4. 先预演：真正停之前，拿一个广告包做一次「停 → 检查 → 还原 → 检查」，确认这台机的还原命令真的能用。停用命令按顺序试：`pm disable-user --user 0`，被拒就 `pm hide`，再不行才 `pm uninstall -k --user 0`（这条必须先单独问我同意，而且要预演过能用 `cmd package install-existing` 或 `pm install -r` 装回来）。
5. 分三组给我看，再动手：
   - 可停：广告、购物支付、上报统计、卖场演示、静默安装、消息推送。
   - 看我用不用：语音助手、投屏、应用商店、账号云服务、第三方影音 K 歌。你列出来我勾，我没勾的一律留着。
   - 禁停：桌面 / 主界面、信号源 / HDMI 切换、输入法、安装器、系统设置和系统 UI、遥控器和蓝牙服务、工厂 / 恢复出厂 / OTA、电视核心服务、WebView、无障碍读屏、HDMI-CEC、DRM。看名字拿不准的也算禁停，问我。
6. 小批量：一批最多 10 个，第一批只停「可停」组里的广告类。每批停完停下来，等我测四样——信号源键切 HDMI、音量、进一次图像设置、播一个片——我说没问题你才继续。
7. 每停一个包，立刻往 `rollback.sh` 追加一行还原命令（`pm enable` / `pm unhide` / `cmd package install-existing`），先写行再算成功。
8. 每批停完用 `adb reboot` 让电视真正重启一次（遥控器的关机键只是待机，不算），重启后检查：画面不黑、桌面在前台、可用内存多少、刚停的包是不是还处于停用状态。有包被系统悄悄恢复了就告诉我这台机对这个方法无效，换下一级方法。
9. 出岔子的固定顺序：黑屏或没反应时，先查系统状态（`dumpsys power`、`dumpsys activity activities`、`screencap`）并告诉我「电视没坏，系统在运行」，再把最近一批整批还原，再真重启；不行就全部还原再重启。不要让我拔电源。同一批出两次问题就全部还原、结束、给我报告。
10. 记录：在同一个文件夹里写 `DEBLOAT-LOG.md`，每一步做了什么、为什么、怎么撤。
11. 老电视不换桌面。不承诺能挡系统更新。给我看截图前把序列号和 MAC 地址打码。

做完给我三样：备份在哪；一句话全部还原的命令；前后对比表（可用内存、停用了几个、每个的还原命令）。

品牌入口和禁停包名参考：sanshengai.top/tools/tv-adb（页面上有各品牌 / 系列的开发者模式步骤、证据等级和已知的坑；找不到我的机型就按通用路径：设置 → 系统 / 关于 → 连按版本号七次 → 开发者选项 → USB 调试，连不上就试 `adb connect IP:5555` 看端口是不是本来就开着）。
